Install Lilliput

This page installs Lilliput on an M-VAVE FM-1 connected to this computer, over USB MIDI. It works in a desktop Chrome, Edge or Opera. It talks to FM-1 directly: nothing is uploaded anywhere.

Read this first. Lilliput is unofficial firmware, not made, endorsed or supported by M-VAVE. Installing it replaces FM-1's firmware and may void any warranty that applies to your device. An interrupted update can leave FM-1 unable to start until it is recovered. Lilliput keeps its sessions in the same flash area other FM-1 firmwares use; another firmware, installed later, may erase them: back them up first. The software comes with no warranty of any kind; you install it entirely at your own risk. Full disclaimer.

Before you start

  1. Use a USB cable that carries data (some carry power only), plugged straight into computer.
  2. Switch FM-1 on, and close any other program using MIDI (a DAW, M-VAVE's app).
  3. When browser asks to let this page control MIDI devices, allow it: update is sent as MIDI system-exclusive messages.

After installing

Switch FM-1 off and on once: Lilliput runs on both of the FM-1's processor cores. It starts with a patch already sounding; turn MASTER up gently. Press HOME for a new patch, turn SELECT (a channel's fader) to find where its loop sings, and read the manual. Your sessions from an earlier Lilliput stay where they were.

If something goes wrong

Stopped part-way? Reload this page and install again: an FM-1 left in update mode is found and the write is finished. If FM-1 starts but does not answer over USB, put it in chip's own update mode — hold OCT− and OCT+ for 5 seconds while it runs — and restore firmware with Melodee's recovery tool (macOS, Linux, Windows) or FM-1-transporter.

Prefer the command line? Build and install from source.
